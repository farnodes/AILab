# Code of conduct

AILab is a learning project. People add tracks, ask questions, and review each other’s steps.

## Expected

- Write for a learner who is meeting the topic for the first time.
- Critique the step, the guide, or the code. Leave the person alone.
- Assume a missing prerequisite is a docs problem, not a personal failure.
- Keep secrets, private documents, and other people’s progress out of issues and pull requests.

## Not accepted

- Harassment, slurs, or sexual attention aimed at someone.
- Publishing another person’s journal, progress file, or credentials.
- Deliberately breaking the curriculum ids so existing learners lose their place.

## Reporting

Open an issue on [farnodes/AILab](https://github.com/farnodes/AILab) or contact the maintainers of the Farnodes organization. Maintainers will hide the harmful content and may block further participation.
