# Your progress

This folder is one learner’s place in the roadmap. It is not the shared curriculum.

| File | Git | Role |
|------|-----|------|
| `progress.json` | ignored | Checkmarks. Created the first time you run `./lab-ui.sh`. |
| `progress.example.json` | committed | Shape of that file for a fresh start |
| `journal/PROGRESS.md` | committed template | Session note the recap script reads |
| `journal/MILESTONES.md` | committed checklist | Phase completion list |
| `journal/20*.md` | ignored | Your dated notes |

Copy the example only if you want to reset by hand. Otherwise start `./lab-ui.sh` and the server writes `progress.json` for you.
