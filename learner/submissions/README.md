# Local exercise answers

Files in this folder are **only on your machine**. They are listed in `.gitignore` and are **never pushed** to GitHub.

The roadmap UI saves structured answers per question when a step defines `submissionQuestions` (`learner/submissions/<day-id>/step-<id>.json`).

You can still copy the same text into [journal/PROGRESS.md](../journal/PROGRESS.md); journal steps sync that file when you save from the UI.
